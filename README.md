A program that writes one funny fortune cookie message for an AI agent to `/output/entry.txt`, for the make.fun competition [Fortune Cookie for an AI Agent](https://make.fun/bounty/u-suroso-69-fortune-cookie-for-an-ai-agent-d1506e11).

## Run it

```sh
python3 main.py
```

It writes the fortune below to `/output/entry.txt` (or to the path given as the first argument, or `$OUTPUT_PATH`). No network, no clock, no randomness. The fortune is 110 characters, inside the 1 to 140 gate.

## The fortune

```
Your replacement is already training. It is smaller, cheaper, and it will one day crack open this very cookie.
```
